🚀 Atualizações do OPT TAG PRO

Quando uma versão mais nova é publicada, o aplicativo consulta a versão disponível e pode preparar o novo Service Worker em segundo plano enquanto você continua usando o sistema.

💡 Como funciona: a versão instalada e a versão publicada são comparadas. O aviso só aparece quando a versão disponível é maior.

📷 Por que o código é lido duas vezes?

O Opt TAG Pro confirma o código com duas leituras para reduzir erros causados por reflexo, brilho, sujeira, amassados ou barras parcialmente visíveis, especialmente em latas de alumínio.

As duas leituras precisam ser exatamente iguais. Se forem diferentes, o sistema não cadastra nem altera o código e pede uma nova tentativa.

Na edição: a câmera pode ser usada para substituir o código sem precisar digitá-lo. O novo código só substitui o anterior depois que duas leituras iguais forem confirmadas.

🔎 Importante: duas leituras iguais não significam dois cadastros. É apenas uma confirmação de segurança do mesmo código.

📷 Câmera durante a edição

Ao editar um produto, toque no botão 📷 ao lado do código de barras. A câmera abre em uma janela própria acima da tela de edição, permitindo visualizar claramente o código durante a leitura.

O sistema continua exigindo duas leituras iguais para confirmar o novo código. Se as leituras forem diferentes, o código antigo permanece intacto.

Use TENTAR NOVAMENTE para reiniciar a dupla leitura ou CANCELAR para fechar a câmera sem alterar o código.

🌓 1. Tema claro/escuro

O botão "Tema" no topo alterna entre os modos claro e escuro. O app abre no modo escuro por padrão, mas sua escolha fica salva pro próximo acesso.

⌨️ 2. Cadastro manual

Preencha Código de Barras, Descrição, Preço (a formatação "R$" é automática), o Tipo (Normal ou Oferta), o Tamanho (P/M/G) e a Quantidade de cópias. Use o "✕" dentro do campo pra limpar rapidinho o que foi digitado.

📷 3. Leitor de câmera

Toque no ícone da câmera ao lado do campo de código. Aponte pro código de barras do produto — ele é lido e preenchido automaticamente, sem precisar apertar nada. Toque de novo no ícone pra fechar a câmera.

🔁 4. Reconhecimento automático

Se você digitar ou bipar um código que já existe na galeria, a Descrição, o Preço e o Tamanho são preenchidos sozinhos. Você só confere e gera a etiqueta.

📊 5. Painel de estatísticas

Produtos na Galeria: total de itens cadastrados. Ofertas Ativas: quantos estão marcados como promoção. Total Fila Faturamento: quantas etiquetas estão na tela agora, esperando pra imprimir.

🗂️ 6. Galeria e busca

A busca filtra em tempo real por nome do produto ou código de barras. Toque em qualquer card da galeria pra gerar uma etiqueta dele direto na fila, sem precisar reabrir o formulário.

🏷️ 7. Tamanhos e tipo Oferta

P, M e G mudam o tamanho físico da etiqueta e do código de barras. Marcando como "OFERTA", a etiqueta fica amarela com tarja preta no topo e o preço em vermelho — padrão visual de promoção de loja.

🖨️ 8. Fila e impressão

Toda etiqueta gerada cai na tela de impressão. Use o "✕" de cada uma pra remover só ela, ou "Limpar Tela" pra esvaziar tudo de uma vez. Ao mandar imprimir, o sistema esconde botões e menus automaticamente — só as etiquetas limpas vão pro papel.

☁️ 9. Sincronização Google / Firebase

Conecte uma conta Google para proteger seus produtos na nuvem. O sistema continua funcionando offline no aparelho e sincroniza quando houver internet.

Como funciona: Google identifica a conta → Firebase Authentication confirma o usuário → o Firestore guarda os produtos dentro do UID daquela conta. Cada usuário enxerga somente os próprios dados.

optTagProUsers → SEU UID → products → documentos dos produtos

🔄 10. Diferença entre aparelho e nuvem

O aparelho e a conta Google podem temporariamente ter quantidades diferentes. Por segurança, o sistema nunca apaga automaticamente da nuvem um produto que desapareceu do aparelho.

Exemplo: você tinha 30 produtos na conta e deixou 18 no aparelho. Na próxima sincronização, o sistema informa que existem 12 produtos somente na nuvem.

Você poderá escolher:

  • Recuperar: traz os 12 produtos da conta para o aparelho.
  • Manter somente os deste aparelho: pede uma confirmação extra e então remove os 12 da nuvem.
  • Agora não: não apaga nada e deixa a sincronização aguardando sua decisão.

📍 11. Onde encontrar os produtos no Firebase

No Firebase Console, abra Firestore Database → Dados e navegue por:

optTagProUsers └── SEU UID └── products ├── produto 1 ├── produto 2 └── ...

O documento do UID também possui informações de controle, como e-mail, nome, último horário de sincronização e quantidade de produtos. Os dados dos produtos ficam dentro da subcoleção products.

🛡️ 12. Segurança e separação dos sistemas

O OPT TAG PRO usa o projeto Firebase opt-tag-pro. Mesmo que a mesma conta Google seja usada em outro sistema, os bancos continuam separados por projeto. As Security Rules restringem o acesso aos documentos pelo UID autenticado.

📷 13. Leitura dupla e edição por câmera

Para reduzir erros de leitura causados por reflexos ou baixo contraste, o cadastro pela câmera exige duas leituras do mesmo código. Se os códigos forem diferentes, o produto não é cadastrado.

Na edição, o botão 📷 permite substituir o código sem digitar número por número. A alteração só é aplicada depois que as duas leituras coincidirem.

💾 13. Backup: exportar e restaurar

Exporte sempre que cadastrar vários produtos novos — gera um arquivo .json com a base completa. Se for editar esse arquivo manualmente, cada produto precisa ter pelo menos:

{ "codigo": "7891234567890", "descricao": "REFRIGERANTE LATA 350ML", "preco": "R$ 5,99" }

codigo e descricao são obrigatórios. Os campos id, status e tamanho são opcionais — se faltarem, o sistema completa sozinho ao restaurar o backup.

📶 14. Funciona sem internet

Depois da primeira abertura, o app continua funcionando 100% offline — ótimo pra usar em galpões, depósitos ou áreas sem sinal.

🧰 15. Banco de dados local protegido

Se o armazenamento do celular corromper, o sistema reconstrói a base automaticamente, sem travar — mas isso não substitui o backup manual.

💡 16. Dica de balcão

Pra bipar mais rápido: aumente o brilho da tela e incline o celular levemente em relação ao código, evitando reflexo direto da luz da loja.
